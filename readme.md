# ForecastOps

ForecastOps is a configuration driven pipeline that captures weather forecast snapshots and tracks how those forecasts change over time.

The project focuses on practical data engineering concerns:

* API ingestion from a live public source
* environment specific configuration for dev, test, and prod
* repeatable pipeline execution
* SQL transformations with a clear operational purpose
* data quality checks
* structured logging and run metadata
* GitHub based testing and promotion
